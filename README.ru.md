# AI Usage Widget — виджет лимитов для Windows 11

Небольшое всегда-поверх-окон окошко, которое показывает **остатки лимитов** для
Claude Code и Codex CLI в реальном времени.

![Обзор](preview/shot_overview.png)

## Возможности

### Основные экраны
1. **Обзор** — остаток текущей 5-часовой сессии по обоим сервисам с таймером сброса
2. **Claude** — сессия + неделя (и Opus-неделя, если есть) со временем сброса
3. **Codex** — сессия + неделя со временем сброса, план, доп. лимиты моделей
4. **Настройки** — интервал обновления, размер окна, режим "поверх всех окон", язык и дневные метки недельных шкал

Недельные шкалы по умолчанию разделены шестью дневными метками на семь равных сегментов, а белая точка отмечает текущий день цикла.

### Индикаторы статуса
- **Статус токена** — цветной бейдж рядом с названием сервиса:
  -  Активен — токен валиден
  -  Истекает — осталось меньше часа
  -  Истёк — нужно залогиниться
- **Таймер обратного отсчёта** — показывает секунды до следующего обновления
- **Красная полоска** — остаток ≤ 15%

### Дневной темп недели

Недельная шкала разделена шестью белыми метками на семь одинаковых дневных сегментов. Белая точка показывает текущий день отдельного недельного цикла, вычисленный по времени его сброса. Поскольку шкала показывает остаток квоты, день 1 находится справа, а день 7 — слева: если заполнение заканчивается правее точки, расход идёт с опережением запаса; если левее — квота расходуется быстрее равномерного темпа. При отсутствии корректного времени сброса метки остаются, а точка не показывается.

Метки включены по умолчанию. Переключатель **Настройки > Отображение > Дневные метки на недельных шкалах** одновременно скрывает или показывает разделители и точки текущего дня.

### Системный трей
При сворачивании в трей виджет продолжает работать в фоне. В трее остаётся одна
постоянная иконка приложения, а в её подсказке показаны недельные остатки Claude
и Codex, время до сброса и баланс OpenRouter.

![Трей](preview/shot_tray.png)

Наведи на иконку — увидишь тултип с подробной информацией. Правый клик:
- **Показать** — вернуть окно
- **Обновить** — запросить свежие данные
- **Выход** — полностью закрыть виджет

### Быстрая авторизация
При истёкшем токене появляется кнопка **"Войти через CLI"** — запускает `claude auth login` или `codex login` в отдельном окне.

## Установка

1. Нужен **Python 3.10+**: https://python.org (при установке отметь *Add to PATH*)
2. В папке виджета запусти **install.bat**. Скрипт создаст `.venv` и установит
   точные версии из `requirements.txt`.
3. Двойной клик по **start_widget.vbs** запустит приложение без консоли.
   Если окружение ещё не создано, лаунчер подскажет сначала выполнить
   `install.bat`. Запуск из терминала:
   ```powershell
   .\.venv\Scripts\python.exe widget.py
   ```

### Автозапуск при старте Windows

Нажми `Win+R` → `shell:startup` → скопируй туда **ярлык** на `start_widget.vbs`

## Откуда берутся данные

Виджет ничего не отправляет наружу, кроме запросов к официальным серверам
самих сервисов. Токены читаются из тех же файлов, что используют CLI:

| Сервис | Токен | Эндпоинт |
|---|---|---|
| Claude Code | `~/.claude/.credentials.json` | `api.anthropic.com/api/oauth/usage` |
| Codex CLI | `~/.codex/auth.json` | `chatgpt.com/backend-api/wham/usage` |

Требование: быть залогиненным в каждом CLI (`/login` в Claude Code, `codex login`).

### Про эндпоинты

Оба эндпоинта — те же, что используют сами CLI и утилиты вроде CodexBar, но они
недокументированные и могут поменяться. Если карточка вдруг перестала обновляться
после апдейта CLI — напиши, поправим парсер (он и так принимает несколько
вариантов имён полей).

## Настройки

### Через интерфейс
Вкладка **Настройки** позволяет изменить:
- **Интервал обновления** — как часто опрашивать API (15-600 секунд)
- **Ширина окна** — 200-800 px
- **Высота окна** — 300-1200 px
- **Поверх всех окон** — вкл/выкл
- **Дневные метки на недельных шкалах** — вкл/выкл (по умолчанию включены)
- **Язык** — Русский / English

Поля настроек работают как черновик: фоновое обновление данных не сбрасывает
несохранённый ввод, а ошибка записи остаётся видимой. Если `config.json`
повреждён, автоматическое сохранение геометрии не перезаписывает его; при явном
сохранении в Настройках сначала создаётся резервная копия
`config.json.corrupt-<timestamp>.bak`.

### Через config.json
```json
{
  "language": "ru",
  "refresh_interval_sec": 60,
  "display": {
    "daily_markers": true
  },
  "window": {
    "width": 380,
    "height": 600,
    "on_top": true,
    "x": null,
    "y": null
  }
}
```

В памяти сохраняются только документированные ключи конфигурации.
Неподдерживаемые или устаревшие ключи, добавленные вручную, игнорируются при
загрузке и исчезают при следующем сохранении `config.json`.

## Возможные проблемы

* **HTTP 401/403** — токен истёк. Нажми "Войти через CLI" или залогинься вручную
* **Пустое окно** — не установлен WebView2 Runtime (на Windows 11 он есть по умолчанию; если нет — https://developer.microsoft.com/microsoft-edge/webview2/)
* **Красная полоска** — остаток ≤ 15%, пора готовиться к сбросу лимитов
* **Иконка Python вместо виджета** — перезапусти приложение, иконка применится после создания окна

## Разработка

### Зависимости
- **pywebview==6.2.1** — окно на базе WebView2
- **pystray==0.19.5** — иконка в системном трее
- **Pillow==12.3.0** — работа с иконкой

### Структура
```
usage-widget/
├── widget.py          # Бэкенд: API, парсинг, трей
├── ui.html            # Фронтенд: интерфейс на HTML/CSS/JS
├── requirements.txt   # Зафиксированные версии зависимостей
├── config.json        # Настройки (создаётся автоматически)
├── icon/
│   ├── 512.png        # Исходная иконка приложения
│   └── app.ico        # Windows-иконка (генерируется автоматически)
├── preview/           # Скриншоты для README
├── install.bat        # Установка зависимостей
└── start_widget.vbs   # Запуск без консоли
```

### Сборка EXE
```bash
pip install pyinstaller
python -m PyInstaller --onefile --windowed --name="AI-Usage" --icon="icon/app.ico" --add-data "ui.html;." --add-data "icon/512.png;icon" --add-data "icon/app.ico;icon" --collect-all pywebview --collect-all pystray widget.py
```
